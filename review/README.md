# Review records

One record per task. Every review here was done by an AI model (Claude Sonnet), acting in
the role the draft protocol gave to an independent reviewer. None was done by a person.
Where a record's heading says "Independent review" or refers to an "independent reviewer",
read it as "AI review": the records are kept as written.

The reviewers could read every suite, including the audit suite X. In several tasks a
reviewer pointed out cases that only X tested, and the resolver then added such cases to
the hidden checks H (T09's record says the resolver wrote its new H cases after reading X).
In others the resolver changed X after review. H and X are therefore not independent.
